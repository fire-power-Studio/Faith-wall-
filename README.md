# FaithWalls — Christian Wallpaper Studio

## Files
- `index.html` — page structure
- `styles.css` — layout and styling
- `app.js` — wallpaper picker, video previews, verse editor, creator and downloads
- `images/` — 15 wallpaper images
- `videos/` — 9 live-wallpaper MP4 files

## Publish on GitHub Pages
1. Upload the contents of this folder to the root of your GitHub repository (keep `index.html` at the root).
2. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
3. Wait for the Pages deployment to finish, then open the published URL.

Asset filenames use lowercase ASCII names to avoid case-sensitivity and special-character URL problems on GitHub Pages. The website downloads video files as MP4s; it cannot directly set the phone's wallpaper from a normal web browser.
